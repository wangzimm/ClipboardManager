# 需求规格说明

## 项目概述

一款运行在 Windows 上的历史剪贴板管理软件，自动记录用户复制的文字和图片，支持查看、搜索、置顶、删除和再次粘贴。

## 功能需求

### F1 - 剪贴板自动监控
- 软件在后台运行时，自动检测剪贴板变化
- 支持文字内容（纯文本）和图片内容（位图）
- 同一内容不重复记录（去重）

### F2 - 内容保留与清理
- 默认保留 3 天
- 用户可选：1 天、3 天、5 天
- 置顶内容不受保留天数限制，永不过期
- 每次启动时自动清理过期内容

### F3 - 内容展示
- 面板在屏幕右上角弹出
- 分为「文字」和「图片」两个标签页
- 按时间倒序排列（最新在最上）
- 置顶内容始终排在最前面
- 卡片形式展示每条内容：
  - 文字卡片：显示文字预览（截断长文本）、复制时间
  - 图片卡片：显示缩略图、复制时间

### F4 - 内容操作
- 点击卡片 → 将内容写回剪贴板，可粘贴使用
- 右键卡片 → 弹出菜单：置顶/取消置顶、删除
- 删除操作需确认

### F5 - 搜索
- 支持关键词搜索文字内容
- 实时过滤，输入即搜
- 搜索范围：文字标签页的所有文字内容
- 图片按时间范围搜索（可选）

### F6 - 启动与激活
- 开机自动启动（可关闭）
- 系统托盘常驻图标
- 快捷键 Ctrl+Shift+V 呼出面板
- 点击托盘图标也可呼出面板

### F7 - 设置
- 保留天数选择：1 天 / 3 天 / 5 天
- 开机启动开关
- 快捷键自定义（可选）

## 非功能需求

### NF1 - 性能
- 剪贴板监控不应造成明显 CPU 占用
- 面板呼出响应时间 < 500ms
- 列表滚动流畅（1000 条记录以内）

### NF2 - 可靠性
- 崩溃后重启不丢失已记录的数据
- 数据库异常时有容错处理

### NF3 - 易用性
- UI 简洁直观，无需学习成本
- 安装即用，无需额外配置

### NF4 - 兼容性
- 支持 Windows 10 及以上系统
- 支持常见图片格式（PNG、JPG、BMP）
