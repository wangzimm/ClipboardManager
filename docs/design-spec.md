# UI 设计规范

## 设计原则

- **简洁**：减少视觉噪音，只展示必要信息
- **直观**：操作符合 Windows 用户习惯
- **高效**：核心操作不超过 2 步

## 色彩规范

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色调 | #E3F2FD | 淡蓝背景（面板） |
| 主色加深 | #BBDEFB | 卡片背景 |
| 强调色 | #42A5F5 | 按钮、选中态、标签页激活 |
| 强调色悬停 | #1E88E5 | 鼠标悬停 |
| 文字主色 | #212121 | 标题、正文 |
| 文字次要 | #757575 | 时间戳、辅助信息 |
| 置顶标识 | #FFA726 | 置顶图标颜色 |
| 危险操作 | #EF5350 | 删除按钮 |
| 边框 | #E0E0E0 | 卡片边框 |

## 字体

- 系统默认字体（Microsoft YaHei 9pt）
- 标题加粗，正文常规
- 时间戳小号字体

## 布局

### 主面板

```
┌──────────────────────────────┐
│  🔍 搜索...                   │  ← 搜索栏
├──────────────────────────────┤
│  [文字]  [图片]              │  ← 标签页切换
├──────────────────────────────┤
│  ┌──────────────────────┐   │
│  │ 📌 文字内容预览...     │   │  ← 卡片（置顶）
│  │     2026-05-14 19:30  │   │
│  └──────────────────────┘   │
│  ┌──────────────────────┐   │
│  │ 文字内容预览...        │   │  ← 卡片（普通）
│  │     2026-05-14 18:00  │   │
│  └──────────────────────┘   │
│  ┌──────────────────────┐   │
│  │ [图片缩略图]          │   │  ← 图片卡片
│  │     2026-05-14 17:00  │   │
│  └──────────────────────┘   │
│                             │
├──────────────────────────────┤
│  ⚙ 设置    保留 3 天         │  ← 底部状态栏
└──────────────────────────────┘
```

### 尺寸

- 面板宽度：360px
- 面板最大高度：600px
- 卡片内边距：12px
- 卡片间距：8px
- 图片缩略图最大高度：120px
- 文字预览最大行数：3 行

### 弹出位置

- 屏幕右上角，距右边缘 20px，距上边缘 20px
- 窗口无边框，带阴影
- 失去焦点时自动隐藏

## 交互

### 呼出与隐藏
- Ctrl+Shift+V → 在右上角弹出面板
- 点击面板外部区域 → 面板隐藏
- 按 Esc → 面板隐藏
- 托盘图标左键单击 → 切换显示/隐藏

### 卡片交互
- 左键单击 → 复制内容到剪贴板，面板短暂提示"已复制"
- 右键单击 → 弹出上下文菜单（置顶/取消置顶、删除）
- 置顶卡片显示图钉图标，背景色微调以区分

### 搜索
- 输入即搜，无需按回车
- 不区分大小写
- 匹配文字内容
- 无结果时显示"没有找到相关内容"

### 设置
- 点击底部齿轮图标或托盘菜单进入设置
- 保留天数：下拉选择（1/3/5 天）
- 开机启动：开关切换
- 设置实时保存
