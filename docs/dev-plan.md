# 分阶段开发计划

## 阶段概览

| 阶段 | 名称 | 目标 |
|------|------|------|
| 1 | 项目基础搭建 | 文件夹、文档、依赖清单 |
| 2 | 数据库 + 剪贴板监控 | 自动记录文字和图片到 SQLite |
| 3 | 系统托盘 + 基础 UI | 托盘图标、面板窗口框架 |
| 4 | 内容卡片 + 列表展示 | 文字/图片卡片、时间倒序、点击回写 |
| 5 | 搜索 + 置顶 + 删除 + 设置 | 完整交互功能、自动清理 |
| 6 | 打包 + 测试 + 收尾 | .exe 安装包、使用说明 |

## 阶段 1：项目基础搭建

### 任务清单
- [ ] 创建项目文件夹结构
- [ ] 创建 docs/ 下所有规范文档
- [ ] 创建 devlog/ 下当日开发日志
- [ ] 创建 CLAUDE.md 指引文件
- [ ] 创建 requirements.txt 依赖清单
- [ ] 创建 resources/ 占位文件

### 验收标准
- 所有文件夹和文件创建完毕
- CLAUDE.md 正确指向各文档路径
- 依赖清单完整可安装

## 阶段 2：数据库 + 剪贴板监控

### 任务清单
- [ ] 实现 database.py：初始化、CRUD、自动清理
- [ ] 实现 monitor.py：轮询剪贴板、去重、信号通知
- [ ] 实现 main.py 基础框架：初始化数据库和监控
- [ ] 编写测试脚本验证数据流

### 验收标准
- 运行后自动在 %APPDATA% 创建数据库
- 复制文字 → 数据库中新增记录
- 复制图片 → 数据库中新增记录（含 BLOB）
- 重复复制相同内容 → 不产生重复记录
- 过期内容被正确清理

## 阶段 3：系统托盘 + 基础 UI

### 任务清单
- [ ] 实现 tray.py：托盘图标、右键菜单
- [ ] 实现 main_window.py：主窗口框架、右上角定位、无边框
- [ ] 实现主题样式表（淡蓝色）
- [ ] 绑定快捷键 Ctrl+Shift+V
- [ ] 实现窗口失焦自动隐藏
- [ ] 实现 ui/__init__.py 模块导出

### 验收标准
- 托盘图标正常显示
- 右键菜单功能完整
- 快捷键能呼出/隐藏面板
- 面板正确出现在右上角
- 点击外部自动隐藏

## 阶段 4：内容卡片 + 列表展示

### 任务清单
- [ ] 实现 card_widget.py：文字卡片、图片卡片
- [ ] 实现 text_tab.py：文字列表，从数据库加载
- [ ] 实现 image_tab.py：图片列表，从数据库加载
- [ ] 实现时间倒序排列、置顶优先
- [ ] 实现卡片点击写回剪贴板
- [ ] 实现"已复制"提示

### 验收标准
- 文字卡片正确显示预览和时间
- 图片卡片正确显示缩略图和时间
- 置顶卡片排在最前
- 点击卡片后内容可粘贴
- 列表滚动流畅

## 阶段 5：搜索 + 置顶 + 删除 + 设置

### 任务清单
- [ ] 实现 search_bar.py：实时搜索过滤
- [ ] 实现卡片右键菜单：置顶/取消置顶、删除
- [ ] 实现删除确认对话框
- [ ] 实现 settings.py：保留天数选择
- [ ] 实现 settings_manager.py：设置读写、开机启动
- [ ] 实现自动清理定时任务

### 验收标准
- 搜索实时过滤，结果正确
- 置顶/取消置顶即时生效
- 删除后数据从数据库移除
- 设置面板功能完整
- 开机启动注册表正确写入
- 过期数据自动清理

## 阶段 6：打包 + 测试 + 收尾

### 任务清单
- [ ] 创建 build.spec 打包配置
- [ ] 使用 PyInstaller 打包为 .exe
- [ ] 全流程功能测试
- [ ] 修复发现的问题
- [ ] 编写 README.md 用户说明
- [ ] 最终验收

### 验收标准
- .exe 文件可独立运行
- 所有功能正常工作
- 用户说明清晰易懂
