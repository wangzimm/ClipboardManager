历史粘贴板

静默运行在 Windows 系统托盘，自动记录复制历史。任何时候按 Ctrl+Shift+V 就能找回之前的内容。

下载 exe 查看源码
📋

自动记录

文字和图片自动入库，重复内容智能去重，更新时间而非新增记录。

🔍

即时搜索

输入关键词快速过滤，在几千条记录中瞬间定位目标。

📌

置顶 & 回收站

高频内容一键置顶永不过期；误删内容进回收站，7 天内可恢复。

🔒

纯本地存储

数据存于 SQLite 本地文件，零网络请求，隐私不外泄。

⚡

全局热键

Ctrl+Shift+V 呼出面板，Esc 隐藏，不打断当前工作流。

🫥

边缘浮动

48px 图标靠边可缩为 8px 细条，触碰即展开，不占屏幕空间。

快速开始

下载 exe 双击运行，或从源码启动

# 安装依赖
pip install -r requirements.txt

# 运行
python src/main.py

# 打包
pyinstaller build.spec

支持 Windows 10 / 11 · Python 3.14 · PySide6 + SQLite
